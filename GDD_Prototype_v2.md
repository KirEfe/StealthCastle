# StealthCastle 2.0 — GDD Прототипа

> Статус: утверждено с дизайнером. Дата: 2026-08-24.
> Это документ по переделке текущего прототипа под новую концепцию.

---

## 1. Обзор

| Параметр | Значение |
|---|---|
| Жанр | Изометрический стелс-роглайт |
| Референс вида | Hades (псевдоизометрия, свободное движение) |
| Движок | Unity 6, 2D URP, чистая 2D-изометрия (спрайты, сортировка по Y) |
| Ядро геймплея | Маскировка в предметы окружения |
| Структура | Забеги: хаб → сборка уровня → прохождение → победа/смерть → хаб |

**Ключевое отличие от старой версии:** вместо 2D бокового платформера — изометрический вид сверху-сбоку со свободным движением; уровень собирается **целиком до входа игрока**, на глазах у него.

---

## 2. Основной цикл забега

1. **Хаб.** Игрок в безопасной зоне. Здесь выбирает артефакты (мета-прогрессия) и запускает следующий уровень.
2. **Сборка уровня.** Уровень собирается целиком из крупных кусков локации **до того**, как игрок получает управление. Сборка происходит визуально на глазах игрока (куски появляются последовательно с эффектом). Это момент предвкушения и планирования.
3. **Прохождение.** Цель: дойти до выхода. Опционально: украсть сокровище (риск/награда).
4. **Итог.**
   - Победа → экран результата → возврат в хаб → награды.
   - Поимка = смерть = конец забега. Временные усиления теряются, мета-прогресс сохраняется.

Уровень конечен — игрок получает ощущение победы и отдыха между уровнями. Никакой бесконечной генерации на лету.

---

## 3. Ключевые механики

### 3.1. Движение
- Свободное перемещение WASD/стик в 8 направлениях, без привязки к сетке.
- Коллизии — простой круговой коллайдер.
- Сортировка спрайтов по Y для корректной глубины.

### 3.2. Маскировка (ядро игры)
- Зажатие кнопки → скан предметов в радиусе → подсветка доступных пропов (outline) → превращение в выбранный предмет.
- Спрайт игрока заменяется спрайтом пропа.
- Таймер дыхания (HUD): ограничивает время маскировки.
- **Медленное движение в маскировке разрешено**, но если враг смотрит на игрока во время движения — заметит.
- Сброс маскировки: истечение таймера / повторное нажатие / обнаружение врагом.

### 3.3. Враги
- Один тип для прототипа: патрульный стражник.
- Состояния: `Patrol` → `Investigate` → `Chase` → `Search` → `Patrol`.
- Конус зрения визуализирован полупрозрачным сектором.
- Патруль по waypoints внутри куска локации. Без NavMesh.
- Правила обнаружения:
  - Неподвижный замаскированный игрок — невидим.
  - Движение в конусе зрения без маскировки → обнаружение.
  - Медленное движение в маскировке в поле зрения врага → постепенное обнаружение (шкала подозрения).
- Принцип честности: игрок всегда понимает, почему его заметили.

### 3.4. Генерация уровня из кусков
- 4–6 префабов крупных кусков: комната, Г-образный коридор, зал с колоннами, тупик с сокровищем, стартовый кусок, кусок с выходом.
- Каждый кусок имеет точки соединения (`ConnectionPoint`: тип проёма + направление).
- Алгоритм: стартовый кусок → случайная цепочка кусков по правилам стыковки → кусок с выходом. Гарантия проходимости.
- Артефакты меняют вероятности выбора кусков и содержимого (враги, сокровища).

### 3.5. Артефакты (первая проверка фишки)
- Выбираются в хабе перед забегом.
- Эффект виден уже на этапе сборки уровня — игрок заранее видит, во что ввязывается.
- Для прототипа: 1–2 тестовых артефакта («больше комнат с сокровищами», «меньше врагов, но они быстрее»).

---

## 4. Провал и смерть
- Поимка = мгновенная смерть = конец забега. Роглайт без компромиссов.
- Теряется: прогресс уровня, временные усиления, валюта забега.
- Сохраняется: разблокированные артефакты, мета-валюта.

---

## 5. Что НЕ входит в прототип
- Бой любого рода (нож, арбалет, открытый бой).
- Множество типов врагов, боссы.
- Полная система артефактов и мета-экономики.
- Звук, сложные анимации, сложный UI (только таймер дыхания и базовый HUD).

---

## 6. План реализации (по этапам)

| Этап | Содержание | Критерий проверки |
|---|---|---|
| 0 | Изометрическая камера + свободное движение | Управление ощущается как в Hades, не пошагово |
| 1 | Куски локации + сборка уровня целиком до входа | Каждый уровень проходим, стыки органичны, сборка приятна |
| 2 | Маскировка (скан, превращение, таймер) | Интуитивно понятно без обучения |
| 3 | Враг: патруль, конус зрения, состояния | Стелс честный, заметившие причины понятны |
| 4 | Цель уровня + цикл хаб → уровень → хаб | Цикл ощущается правильно, есть ощущение победы |
| 5 | Первый артефакт, влияющий на генерацию | Игрок чувствует влияние артефакта на игру |

Оценка: этапы 0–3 ≈ 2–3 недели соло, этапы 4–5 ≈ ещё неделя.

---

## 7. Технические решения
- Чистая 2D-изометрия: спрайты под углом ~45°, сортировка по Y. Без 3D-мешей.
- Патруль и преследование — waypoints + прямое движение к цели. NavMesh не используется.
- Все числа (радиусы, таймеры, скорости) — [SerializeField] или константы, никаких magic numbers.
